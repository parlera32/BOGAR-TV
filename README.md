# BOGAR TV

Dört sekmeli Android IPTV liste okuyucu başlangıç projesi.

- Kanallar: yüklenen M3U listesindeki kanalları gösterir
- Listeler: GitHub RAW HTTPS M3U bağlantısından liste okur
- Favoriler: sonraki sürüm için ayrılmıştır
- Ayarlar: uygulama bilgisi

**Önemli:** Bu bir ilk sürümdür. Dahili video oynatıcı yoktur; Android'de yüklü uygun bir oynatıcıya yönlendirir. Kanal içeriği sağlanmaz. Sadece kullanım hakkınız olan yayınları ekleyin.

GitHub Actions > Build BOGAR TV APK > Run workflow ile debug APK derlenebilir.
